# VitaWell — Wellness Landing Page

A responsive, single-page wellness website inspired by the supplied reference image, with original implementation and additional interactions.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser. No build step or package installation is required.

## Included
- Responsive desktop, tablet, and mobile layouts
- Floating hero benefit badges and a gently floating hero image
- Scroll reveal transitions and active navigation state
- Dark/light theme toggle
- Feature cards with hover motion
- Client-side wellness coach tips
- Interactive hydration counter
- Guided breathing cycle
- Sign-up, progress check-in, and bedtime-plan modal demos
- Reduced-motion accessibility support

## Notes before production
This is a front-end demo. Form submissions and wellness trackers do not connect to a backend and session state resets on reload. Add authentication, a database, validated API endpoints, consent/privacy notices, and production security before collecting personal information. Images and fonts load from Unsplash and Google Fonts, so an internet connection is needed for those assets.
